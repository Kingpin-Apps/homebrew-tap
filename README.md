# Kingpin-Apps Tap

## How do I install these formulae?

`brew install kingpin-apps/tap/<formula>`

Or `brew tap kingpin-apps/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "kingpin-apps/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
